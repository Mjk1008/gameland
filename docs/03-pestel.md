- **Economic** — inflation, currency, disposable income, hardware import costs, gamenet economics.

- **Technological** — internet quality/filtering, mobile penetration, local app stores, payment rails.
- **Environmental** — (minor) electricity reliability for gamenets.
- **Legal** — gambling/قمار ambiguity, raffle law, content/platform licensing, data.
