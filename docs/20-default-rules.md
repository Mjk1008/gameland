# 20 — قوانین واحد گیم‌لند (نسخهٔ پیش‌فرض)

**Stage:** Build · **Status:** 📝 v1 default · **Type:** rules content (fa)
**نقش:** این «قوانین پیش‌فرض» هر مسابقه است. ادمین می‌تواند هنگام ساخت ایونت یک فایل `.md` جدید آپلود کند که جای این را بگیرد. **بخش الف** (عمومی) برای همهٔ رشته‌ها یکسان است؛ **بخش ب** (اختصاصی هر بازی) با ارسال قوانین هر بازی توسط برگزارکننده کامل می‌شود.

> ترکیبی از قوانینی که داشتیم (ساختار، امتیازدهی، چارچوب مالی، رفتار) + مدل واقعی مسابقات (مقدماتی چندشهری → فینال ۱۲۸، سهمیه شهری، پخش بلیط، قرعه‌کشی مخفی).

## بخش الف — قوانین عمومی (همهٔ رشته‌ها)

### ۱. ساختار مسابقه

- هر مسابقه می‌تواند **تک‌مرحله‌ای** (یک مکان، یک براکت) یا **چندمرحله‌ای** باشد.
- ساختار پرچم‌دار (فیفا): **مقدماتی در شهرها → فینال ۱۲۸ نفره در تهران**.
- هر **مرحله/دوره** تاریخ و محل برگزاری مستقل دارد (مثلاً مقدماتی ۱ تا ۳، فینال ۳ تا ۷).
- همهٔ مسابقات **حذفی تک** هستند: باخت = حذف آن بلیط.

### ۲. بلیط / سهم (۱ تا ۶)

- هر بازیکن در هر مقدماتی می‌تواند **۱ تا ۶ بلیط** بگیرد.
- **بلیط = یک شانس ورود** به یک براکت. چند بلیط = چند شانس مستقل.
- **قانون پخش (مقدماتی):** بلیط‌های یک بازیکن در **براکت‌های متفاوت** قرار می‌گیرند — در مقدماتی هیچ بازیکنی با خودش روبه‌رو نمی‌شود.
- **در فینال این استثنا برداشته می‌شود** — بلیط‌های یک بازیکن ممکن است به هم بخورند.
- **چرا بلیط بیشتر؟** بلیط = شانس دوباره. بازیکن تازه‌کار به‌خاطر استرس ممکن است زود حذف شود؛ بلیط بیشتر یعنی تلاش دوباره در براکت دیگر. بازیکن قوی بلیط بیشتر می‌خرد تا شانس رساندن **۳ seed کامل** به فینال را بالا ببرد.

### ۳. صعود از مقدماتی به فینال

- از هر شهر، تعداد مشخصی به فینال ۱۲۸ صعود می‌کنند — **سهمیه را ادمین تعیین می‌کند** (متناسب با تعداد شرکت‌کنندهٔ آن شهر). مثال: اصفهان ۱۰۰ نفر → ۱۰ صعود؛ اهواز ۵۰ نفر → ۵ صعود.
- تعداد صعود از **هر براکت** پیش از شروع مشخص و **قابل‌نمایش** است (سیت‌های صعود سبز مشخص می‌شوند).
- **سقف ۳ seed:** هر بازیکن حداکثر **۳ بلیط** را می‌تواند به فینال ۱۲۸ برساند، حتی اگر بیشتر واجد شرایط شوند.

### ۴. قرعه‌کشی

- قرعه‌کشی **مخفی** است تا زمانی که ادمین آن را **رونمایی** کند — بازیکن از ابتدا نمی‌داند در چه براکتی و با چه کسی بازی دارد.
- قرعه‌کشی **دستی یا تصادفی** توسط ادمین انجام می‌شود.

### ۵. امتیازدهی رنکینگ ملی

امتیاز هر مقام × ضریب تایر رویداد (منبع واحد: `points_for_placement`):

| مقام | امتیاز پایه |
|---|---|
| قهرمان | ۱۰۰۰ |
| دوم | ۸۰۰ |
| سوم | ۵۰۰ |
| چهارم | ۴۰۰ |
| ۵–۸ | ۲۵۰ |
| ۹–۱۶ | ۱۵۰ |
| ۱۷–۳۲ | ۸۰ |
| ۳۳–۶۴ | ۴۰ |
| ۶۵–۱۲۸ | ۲۰ |

**ضریب تایر:** ماژور (S) ×۱.۰ · گیم‌لند (A) ×۰.۸ · آل‌استار (B) ×۰.۵ · محلی (C) ×۰.۳.
امتیاز در پنجرهٔ **۵۲ هفتهٔ اخیر** محاسبه می‌شود؛ **عناوین قهرمانی هیچ‌وقت منقضی نمی‌شوند**.

### ۶. رفع تساوی

۱) امتیاز بیشتر ۲) تعداد رویداد بیشتر ۳) بهترین مقام تاریخی ۴) تازه‌ترین رویداد.

### ۷. چارچوب مالی و حقوقی

- جایزه **کاملاً از طرف حامیان مالی** تأمین می‌شود. هیچ بخشی از ورودی بازیکنان به جایزه نمی‌رود.
- ورودی/بلیط = **هزینهٔ سرویس مهارتی** (organizing fee)، نه شرط‌بندی.
- این چارچوب با مادهٔ ۷۰۵ ق.م.ا. منافات ندارد (عناصر قمار = شرط مالی + شانس، هیچ‌کدام برقرار نیست).

### ۸. رفتار حرفه‌ای

- توهین/تهدید/تخریب حریف → اخطار، در تکرار حذف.
- چیت/هک → حذف دائم + حذف امتیاز رنکینگ.
- چندحسابی → ادغام حساب و کسر امتیاز.
- تأخیر بیش از حد مجاز در حضور برای بازی → باخت تکنیکی (no-show).
- قطع عمدی/اتصال ضعیف → طبق تشخیص داور، باخت تکنیکی.

### ۹. داوری و اعتراض

- تصمیم داور در زمین ملاک است.
- اعتراض فقط تا پیش از شروع بازی بعدی همان بازیکن پذیرفته می‌شود.
